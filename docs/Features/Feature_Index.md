## 🏛️ Project Architecture at a Glance

The project follows strict **Clean Architecture** principles to ensure maintainability:

- **Web (UI Layer)**: ASP.NET Core 10, Vanilla JS, Glassmorphism CSS.
- **Application**: Business Logic, Facades, and DTOs.
- **Domain**: Core Entities (Song, User, Payment).
- **Infrastructure**: PostreSQL, YouTube API, PayOS, Semantic Kernel.
